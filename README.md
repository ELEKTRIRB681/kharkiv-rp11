# Kharkiv RP — Вебсайт (Інструкція)

Коротко: цей репозиторій містить простий вебсайт для Kharkiv RP з бекендом на Python standard library та фронтендом HTML/CSS/JS.

Локальні вимоги:
- Python 3.10+

Швидкий запуск локально:

1) Запустіть Python-сервер

```bash
cd rp-server
python server.py --port 3000
```

Після змін у `server.py` перезапустіть поточний Python-процес, щоб ngrok використовував оновлену валідацію.

2) Відкрийте в браузері

Перейдіть за адресою: http://localhost:3000

Публічний доступ через ngrok:

1) Завантажте та встановіть ngrok з https://ngrok.com
2) Запустіть локальний сервер (див. вище)
3) В іншому терміналі виконайте (замініть 3000 на порт, якщо змінено):

```bash
ngrok http 3000
```

4) ngrok виведе тимчасову публічну адресу виду `https://xxxxxx.ngrok.io` — цю адресу можна використовувати для запрошень, вебхуків або демонстрацій.

Довідка по зміні правил та вмісту:
- Правила сервера доступні через API: `GET /api/rules` (JSON)
- Статус сервера: `GET /api/status` (JSON)

Структура проекту:
- `server.py` — статичний сервер, API та SSE-оновлення
- `data.json` — єдине централізоване сховище записів
- `index.html`, `ranks.html`, `licenses.html`, `admin.html` — фронтенд сторінки

Якщо потрібна допомога з розгортанням або додатковими функціями (авторизація, панель адміністрування, база даних), напишіть, і я допоможу розширити проект.
